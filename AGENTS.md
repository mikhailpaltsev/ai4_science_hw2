# AGENTS.md — Домашняя работа №2 «Проверка»

## Репозиторий

https://github.com/mikhailpaltsev/ai4_science_hw2

Основная ветка: `hw2-final`.

Все команды выполняются из корня репозитория, где находятся `requirements.txt`, `checks/` и `run_experiment.py`.

## Подготовка окружения

Требуется Python 3.11.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Основная команда проверки

```bash
python -m pytest checks -q && python run_experiment.py full
```

Команда запускает автоматические проверки свойств модели, проверки договора о данных и тесты с библиотекой Hypothesis. Затем выполняется вычислительный эксперимент с пятью фиксированными seed.

В эксперименте рассчитываются RMSE экспоненциальной и базовой моделей, парное улучшение, 95%-й доверительный интервал и итоговый вердикт.

Если тесты не проходят, эксперимент не запускается.

Последний подтверждённый запуск: **29 тестов прошли**, полный эксперимент завершён успешно.

## Дополнительные режимы

```bash
python run_experiment.py dry
python run_experiment.py smoke
python run_experiment.py sweep
python run_experiment.py full
```

Результаты сохраняются в каталоге `results/`.

## Обнаруженная ошибка

Для проверки чувствительности верификатора была намеренно изменена формула модели:

- Правильная реализация: `np.exp(-lam * t_arr)`.
- Ошибочная реализация: `np.exp(+lam * t_arr)`.

Результаты зафиксированы в файлах:

- `results/caught_error_before.txt` — 4 теста не прошли, 20 прошли.
- `results/caught_error_after.txt` — 24 теста прошли.

Эти результаты относятся к первоначальному набору из 24 тестов. Позднее были добавлены пять проверок Hypothesis.

Исходная ошибочная версия хранится в истории разработки; её публикация отдельной веткой в текущем репозитории требует подтверждения.

## Ограничения

Проверки выполняются на синтетических данных. Для запуска не требуются реальные медицинские данные пациентов.

Успешный запуск верификатора подтверждает проверяемые свойства реализации, но не доказывает пригодность одноэкспоненциальной модели для реальных клинических наблюдений.
