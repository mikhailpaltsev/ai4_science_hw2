# AI4Science — ДЗ №2 «Проверка»

**Направление:** вычислительная верификация одноэкспоненциальной модели изменения мощности дозы после терапии I-131. Проверки и численный эксперимент проводятся **на синтетических данных**.

> **Для преподавателя:** окончательная версия находится в этом репозитории, в [теге `hw2`](https://github.com/mikhailpaltsev/ai4_science_hw2/tree/hw2). Рабочая ветка — [`hw2-final`](https://github.com/mikhailpaltsev/ai4_science_hw2/tree/hw2-final). Ветка `main` не является версией для проверки ДЗ.

## Пояснение к истории папок и репозиториев

Во время выполнения задания я допустил **организационную ошибку при работе с папками и Git**: первоначально разрабатывал ДЗ №2 в каталоге `first_project/hw2` внутри родительского Git-репозитория `first_project`, который был связан с другим репозиторием GitHub (`doserate`). Кроме того, у меня существовала отдельная папка `AI4Science/hw2`. Из-за этого некоторое время команды Git и ссылки на коммиты относились к разным рабочим каталогам и репозиториям.

Чтобы проверяющему не приходилось разбираться в этих путях, я **выделил ДЗ №2 в самостоятельный репозиторий** [`ai4_science_hw2`](https://github.com/mikhailpaltsev/ai4_science_hw2), сохранив историю разработки, в том числе первоначальную фиксацию методики перед результатами. После переноса были исправлены пути и ссылки в документации, заново проверены зависимости, тесты и воспроизводимость на чистом клоне.

**Для сдачи используется только `ai4_science_hw2` с тегом `hw2`.** Старый репозиторий `doserate`, родительский каталог `first_project` и локальные дубли папки `hw2` не нужны для проверки. Исходные данные пациентов в этот репозиторий не включены.

Эта путаница с Git **не является намеренной ошибкой в математической модели**: отдельный эксперимент с преднамеренной ошибкой описан ниже.

## Быстрая проверка

Требуется **Python 3.11**. Команды выполняются из корня клонированного репозитория:

```bash
git clone https://github.com/mikhailpaltsev/ai4_science_hw2.git
cd ai4_science_hw2
git switch --detach hw2

python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest checks -q
python run_experiment.py full
```

На проверенной финальной версии получено **`29 passed`**. Полный синтетический эксперимент с пятью фиксированными seed (`11, 22, 33, 44, 55`) воспроизводит следующие результаты:

| Показатель | Результат |
|---|---:|
| Среднее парное улучшение RMSE | 2,4775 мкЗв/ч |
| 95%-й доверительный интервал | [2,4439; 2,5111] мкЗв/ч |
| Заранее заданный практический порог | 0,2 мкЗв/ч |
| Итог | Преимущество на синтетических данных подтверждено |

Эти результаты **не являются выводом о клинической применимости** модели к реальным пациентам.

## Намеренная ошибка: «до» и «после»

Для демонстрации способности верификатора обнаруживать дефект создана отдельная ветка [`hw2-intentional-bug`](https://github.com/mikhailpaltsev/ai4_science_hw2/tree/hw2-intentional-bug), коммит [`85a85db`](https://github.com/mikhailpaltsev/ai4_science_hw2/commit/85a85db). В ней намеренно заменён знак в показателе экспоненты: `exp(-λt)` → `exp(+λt)`.

На исходном наборе проверок эта версия даёт **`4 failed, 20 passed`**, а восстановленная исправная версия того же исторического набора — **`24 passed`**. Впоследствии проверки расширены; на окончательной исправной версии проходят **29 тестов**. Это разные этапы истории тестов, а не противоречащие результаты.

Сохранённые протоколы: [`results/caught_error_before.txt`](results/caught_error_before.txt) и [`results/caught_error_after.txt`](results/caught_error_after.txt). В основной ветке намеренная ошибка отсутствует; объединять ошибочную ветку с рабочей **не нужно**.
