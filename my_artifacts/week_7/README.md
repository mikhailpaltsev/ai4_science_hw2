# Артефакт недели 7 — Декомпозиция и проверки свойств

## Цель

Декомпозировать задачу проверки одноэкспоненциальной модели мощности дозы после терапии I-131 и проверить корректность её программной реализации.

Проверяемая модель:

`D(t) = 0.2 + A * exp(-λt)`

## 1. Декомпозиция задачи

Задача разделена на четыре подцели:

1. **Проверка математической модели** — фоновый уровень, монотонность, восстановление параметров и преобразование единиц времени.
2. **Проверка входных данных** — структура Excel, три повторных измерения, соответствие измерений временным точкам.
3. **Проверка численного эксперимента** — генерация синтетических данных, сравнение с базовой моделью, оценка неопределённости.
4. **Проверка чувствительности верификатора** — намеренное внесение ошибки и проверка её обнаружения.

Подробное дерево приведено в [SUBGOALS.md](SUBGOALS.md).

## 3. Проверки свойств

Верификатор проверяет:

- Мощность дозы не опускается ниже фона.
- Модель монотонно убывает.
- Параметры восстанавливаются по данным без шума.
- Перестановка пар «время — измерение» не меняет оценку.
- Переход от часов к суткам корректно изменяет коэффициент убывания.
- Перестановка трёх повторных измерений не меняет их среднее.
- Данные разных пациентов не должны смешиваться.
- Измерения должны оставаться связанными с правильными временными точками.

Реализация проверок находится в `checks/`.

## 4. Как запустить

Из корня репозитория `ai4_science_hw2`:

```bash
python -m pip install -r requirements.txt
python -m pytest checks -q
```

## 5. Результат и ограничения

Исторически исправленная версия прошла 24 теста. После добавления пяти property-based тестов Hypothesis текущий набор содержит 29 тестов; все они прошли на чистом клоне.

Внесённая ошибка в показателе экспоненты была обнаружена четырьмя тестами. Это подтверждает чувствительность верификатора к конкретному дефекту.

Проверки выполнены на синтетических данных. Они не доказывают пригодность одноэкспоненциальной модели для реальных клинических наблюдений.

Пять проверок Hypothesis из `checks/test_hypothesis_properties.py` фактически запущены вместе с остальными тестами: `29 passed in 17.82s` на чистом клоне Python 3.11.
