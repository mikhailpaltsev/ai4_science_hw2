# Артефакт недели 6 — Верификатор

## Проверяемая задача

Корректность реализации одноэкспоненциальной модели мощности дозы после терапии I-131.

Модель:

`D(t) = 0.2 + A * exp(-λt)`

Проверяются математические свойства модели, обработка измерений и воспроизводимость численного эксперимента на синтетических данных.

## Основные артефакты

- [METHOD.md](../../METHOD.md) — заранее зафиксированная методика.
- [AGENTS.md](../../AGENTS.md) — команды запуска.
- [checks/](../../checks/) — автоматические проверки.
- [results/](../../results/) — результаты эксперимента и обнаружения ошибки.
- [diary.md](../../diary.md) — журнал работы.

## Как воспроизвести

Из корня репозитория `ai4_science_hw2`:

```bash
python -m pip install -r requirements.txt
python -m pytest checks -q
python run_experiment.py full
```

## Результаты

В историческом исправленном прогоне исходного набора прошли 24 теста. В актуальной версии на чистом клоне прошли 29 тестов (включая пять проверок Hypothesis).

Полный эксперимент проведён на пяти фиксированных seed. Среднее улучшение RMSE относительно постоянной базовой модели составило 2,4775 мкЗв/ч, 95%-й доверительный интервал — [2,4439; 2,5111] мкЗв/ч.

## Пойманная ошибка

В отдельной Git-ветке `hw2-intentional-bug` намеренно изменён знак показателя экспоненты с отрицательного на положительный.

- [До исправления](../../results/caught_error_before.txt): 4 теста упали, 20 прошли.
- [После исправления](../../results/caught_error_after.txt): 24 теста прошли.

Эта проверка показывает, что верификатор обнаруживает конкретную ошибку реализации.

## Ограничение

Проверки выполняются на синтетических данных и не доказывают пригодность модели для реальных клинических измерений.
